# Для Cursor на новом компьютере

Этот файл — и для человека, и для агента Cursor. На чистой машине нет Node и React. Их не копируют с флешки, их ставят заново.

Если ты **агент Cursor**: прочитай всё, затем помоги с шага 4. Шаги 1–3 человек делает сам. Не запускай `npm run db:reset` и `npm run setup`, если уже есть `prisma/dev.db` — сотрётся база.

Если ты **человек**: сделай пункты 1–3, потом открой эту папку в Cursor и напиши в чат: «прочитай CURSOR.md и запусти сайт».

---

## 1. Поставить Node.js

1. Откройте https://nodejs.org
2. Скачайте **LTS** для Windows (нужна **20 или новее**).
3. Установите. Включите Add to PATH и npm.
4. Закройте все окна терминала и Cursor, откройте заново.
5. Проверка в cmd:

```bat
node -v
npm -v
```

Должны появиться номера версий. React отдельно ставить не нужно: он ставится через `npm install`.

## 2. Поставить Cursor

https://cursor.com — Cursor для Windows, затем вход в аккаунт.

## 3. Скопировать проект

Не запускайте сайт с флешки. Скопируйте папку на диск, например на Рабочий стол. В Cursor: **File → Open Folder**.

## 4. Установить зависимости и запустить

В терминале Cursor:

```bat
node -v
npm install
npm run dev
```

Откройте http://localhost:3000

Если нет `.env`:

```bat
copy .env.example .env
```

Если нет `prisma/dev.db`:

```bat
npm run setup
npm run dev
```

`setup` создаёт базу заново и затирает заказы, если они были.

## Входы

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin  
  локально: `admin@weekend.local` / `admin1234`
- Кабинет родителя: после оформления, логин — телефон
