# Выездной детский спортивный уикенд

Сайт записи на выезды: каталог баз, живые фото и видео, корзина из нескольких заездов, оформление, тестовая оплата, кабинет родителя и админка.

**Перенос на другой компьютер (пустой ноутбук, флешка):** откройте [CURSOR.md](./CURSOR.md). Node и React с флешки не копируют — их ставят заново, затем `npm install` и `npm run dev`.

Домен пока не подключён. Локально всё поднимается из этой папки.

## Стек

- Next.js 15, App Router, TypeScript
- SQLite + Prisma — базы, заезды и заказы правятся без правки кода
- Абстракция `PaymentProvider`: мок, ЮKassa, Т-Касса, CloudPayments
- amoCRM: живой клиент или мок, очередь с ретраями
- Медиа: исходники в `media/{база}/медиа базы` и `медиа с отдыха на базе`, сжатые копии в `public/media/bases`

## Быстрый запуск

Нужны Node.js 20+ и ffmpeg (уже использовался для видео).

```bash
npm install
npm run media:process
npm run setup
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- Админка: [http://localhost:3000/admin](http://localhost:3000/admin)  
  `admin@weekend.local` / `admin1234`
- Кабинет родителя появляется после первого оформления заказа. Логин — телефон, пароль задаёте на чекауте.

`npm run setup` создаёт базу `prisma/dev.db` и пять площадок: Солнечный остров, Парк Сказов, Хрустальная, Баден-Баден, Пески.

## Переменные окружения

Скопируйте `.env.example` в `.env` при необходимости. Важно:

| Ключ | Зачем |
| --- | --- |
| `DATABASE_URL` | SQLite по умолчанию. Для Postgres замените провайдер в `prisma/schema.prisma` |
| `APP_URL` | Адрес сайта. На проде укажите https-домен |
| `AUTH_SECRET` | Секрет сессий, не короче 16 символов |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | Первый админ, создаётся сидом |
| `PAYMENT_PROVIDER` | `mock` / `yookassa` / `tkassa` / `cloudpayments` |
| `PAYMENT_SHOP_ID` / `PAYMENT_SECRET_KEY` | Реквизиты кассы |
| `AMO_DOMAIN` | По умолчанию `recordekb.amocrm.ru` |
| `AMO_ACCESS_TOKEN` | Пусто — сделки только пишутся в лог |
| `AMO_PIPELINE_NAME` | Ищем воронку «СПОРТИВНЫЕ СЕКЦИИ» |
| `AMO_ENABLED` | `true`, когда токен настоящий |

Те же поля можно заполнить в админке: **Настройки**. Значения из админки важнее, чем `.env`.

## Как добавить базу

1. Войдите в админку.
2. **Базы → Добавить базу**.
3. Заполните название, район, описание, возраст, удобства (через запятую).
4. Загрузите обложку, фото, видео и постер.
5. Включите «Опубликовать».

Описание и ссылки на официальные сайты уже в карточках. Новые фото кладите в нужную папку базы или загружайте в админке с пометкой «сама база» / «как мы отдыхаем». Пустая папка = пустой блок на сайте.

## Как добавить заезд

1. **Заезды → Новый заезд**.
2. База, даты заезда и выезда, цена за ребёнка, лимит и остаток мест.
3. Статус считается сам: 0 мест — закрыт, 4 и меньше — мало мест. Можно закрыть вручную.

Покупка всегда привязана к конкретному заезду (база + даты), не к абонементу.

## Как проходит заказ

1. База → фото/видео → дата и число детей → корзина.
2. На оформлении: ФИО и телефон родителя, email по желанию, дети по каждой путёвке, согласие на ПДн, пароль кабинета.
3. Места резервируются сразу. Если оплата падает — места возвращаются.
4. После успеха заказ виден в кабинете родителя и в админке.

## Как включить оплату

Сейчас работает тестовый контур `/pay/mock`: «Оплатить успешно» или «Имитировать ошибку». Оба варианта бьют в `/api/payments/webhook` с идемпотентностью.

Когда выберете кассу:

1. В админке укажите провайдера и ключи.
2. Пропишите `APP_URL` боевого домена.
3. В кабинете ЮKassa / Т-Кассы / CloudPayments укажите webhook: `https://ваш-домен/api/payments/webhook`.
4. Проведите тестовый платёж. Повторный webhook с тем же `eventKey` не проведёт заказ дважды.

Код провайдеров: `src/lib/payments`. Интерфейс один, реализации разные.

## Как включить amoCRM

1. Выпустите долгосрочный токен в `recordekb.amocrm.ru`.
2. Вставьте его в `.env` или в настройки админки.
3. Включите «живой amoCRM».
4. Воронка ищется по имени `СПОРТИВНЫЕ СЕКЦИИ`. Если такой нет — берётся первая доступная.

На оплаченный заказ ставится сделка на каждого ребёнка:

`{база} {даты} {ребёнок} {возраст}л {телефон}`

Тег `уикенд`, контакт — родитель. Если amoCRM недоступна, задача остаётся в очереди и ретраится. Повторить вручную: `POST /api/amocrm/retry`.

Без ключей сайт не ломается: пишет мок в консоль сервера.

## Медиа

Исходники лежат в `media/{название базы}/`:

- `медиа базы` — фото самой площадки
- `медиа с отдыха на базе` — наши фото и видео с выезда

Если папка пустая, на сайте блок честно пустой. Сжатые копии: `public/media/bases/{slug}/place|stay`. Повтор: `npm run media:process`. Загрузки из админки — в `public/uploads`. Логотип: `public/brand/logo.png`.

## Как выложить позже

1. Купите хостинг с Node.js (Vercel, Timeweb, Selectel, свой VPS).
2. Залейте репозиторий, задайте переменные из `.env.example`.
3. Для SQLite на Vercel лучше сменить БД на Postgres: поменяйте `provider` в Prisma и `DATABASE_URL`.
4. Соберите: `npm run build && npm run start` или подключенный Git.
5. Привяжите домен в панели хостинга, обновите `APP_URL`, SSL выдаст хостинг.
6. Смените `AUTH_SECRET` и пароль админа.
7. Замените заглушки контактов и текст политики ПДн.
